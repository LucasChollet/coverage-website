SerenityOS Coverage Reports

Generated from commit hash.

This website contains coverage reports for the SerenityOS repository. The reports are generated nightly, by running our test suite with Clang's code coverage feature.

Results are aggregated with two different methods:

  • A global report
  • Per-component reports

Access per-component reports

Methodology

The global report is created by aggregating the result of every test in a single report.

On the other hand, per-component reports only include the result from the test of the component. This has the advantage of only showing direct testing rather than including transitive testing. For example, a AK::Vector feature used in LibIMAP might be marked as covered in the global report because it's reached from LibIMAP's own tests without being covered by AK tests.
